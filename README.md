# Ankita Tiwari — Personal Portfolio

A responsive, single-page portfolio built with HTML5, CSS3 and Vanilla JavaScript. It is ready for GitHub Pages and requires no build tools or backend.

## Preview locally
Open `index.html` in a browser. For best results, use a local static server or GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `ankita-portfolio`).
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Update your details
- Edit personal details and sections in `index.html`.
- Replace `assets/images/profile-photo.jpg` to change the profile photo (keep the same filename or update the image path in HTML).
- Replace `assets/documents/resume.pdf` with your latest resume.
- Add verified project or certificate information only when available. The current CV did not provide projects or certificates, so those sections are not displayed.
- Add LinkedIn/GitHub links after you have the correct profile URLs.
- Replace the placeholder notes for institute names and passing years when confirmed.

## Files
- `index.html` — page content
- `css/style.css` — responsive styling and themes
- `js/script.js` — navigation, theme toggle and reveal animations
- `assets/images/profile-photo.jpg` — supplied profile portrait
- `assets/documents/resume.pdf` — resume prepared from the supplied CV details
